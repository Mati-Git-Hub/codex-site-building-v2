# PB101 CSS-juhendi kontroll

Kasuta enne saidi arendust ning klasside, tokenite või komponentide süsteemi muutmisel.

1. Leia projekti juur ja loe AGENTS.md. Loe juure suhtes docs/pb101-css.md; ära eelda, et töökaust on oskuse kaust.
2. Kontrolli iga PB101 reegli allikaseost. Erista algupärane ettepanek kontrollitud õpetuspõhimõttest. Koosta täpne versioon ja hangi kasutaja kinnitus enne arendust. Puuduva allika korral ära märgi G2 läbituks.
3. Salvesta projekti tõendiregistrisse sisend, versioon, tulemus, piirangud ja järgmine nõutav otsus. Mall: templates/project-record.md.

Valmisolek: vajalik värav on tõenditega läbitud või sõltuv töö on selgelt blokeerituks märgitud. Agent ei kinnita enda tööd kasutaja nimel.
