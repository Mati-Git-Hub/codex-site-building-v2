# Codexi veebiarenduse juhend v2

Eestikeelne töökorraldus uute veebide loomiseks ja olemasolevate hooldamiseks. See on uus eraldiseisev hoidla, mitte `Mati-Git-Hub/codex-site-building` asendus ega selle muudatus.

Alusta [AGENTS.md](AGENTS.md) failist. Kopeeri projekti juurkausta `AGENTS.md` ja kaustad `docs/`, `checklists/`, `templates/` ning `.agents/skills/`, säilitades kaustastruktuuri. Kontrolli, et agent leiab oskused ja saab avada mõlemad kinnitatud alusdokumendid. Hoidla ise on juhend, mitte valmis veeb ega juba kinnitatud projekt.

## Lugemisjärjekord
1. [Nõuded ja tõendite seis](docs/requirements.md).
2. [Töövoog ja kinnitused](docs/workflow.md).
3. [Paper MCP ja disainisüsteem](docs/design.md).
4. [Kinnitatud PB101 CSS-täppisjuhend v1.0](docs/pb101-css.md).
5. [Platvorm ja kulud](docs/platform.md), [litsentsialus v0.4](docs/licenses-v0.4.md).
6. [Bricks](docs/wordpress-bricks.md) või [Astro/Cloudflare](docs/astro-cloudflare.md).
7. [Vormid ja e-post](docs/forms-email.md), [privaatsus ja müük](docs/privacy-commerce.md), [SEO](docs/seo.md).
8. [QA ja avaldamine](docs/qa-launch.md), [hooldus ja turvalisus](docs/maintenance-security.md).

[Täidetavad projektikirjed](templates/project-record.md) ja [kontrollnimekirjad](checklists/gates.md) annavad otsustele auditeeritava kuju.
